# Answering technique: CER, templates, MCQ routine, keywords

Most lost marks at P3 are **technique**, not knowledge: the idea is right but the
answer has no evidence, no science reason, or answers a different question. This
file is the fix.

---

## 1. CER — Claim, Evidence, Reasoning

| Part | Kid version | What it is | Sentence starter |
|---|---|---|---|
| **C**laim | **Say it** | the answer / choice / Yes or No | "Material R." / "No," / "Stage X is the larva." |
| **E**vidence | **Show it** | a fact **from this question** — table number, diagram observation | "The table shows…" / "R absorbed the most water (90 ml)…" / "Y was only attracted…" |
| **R**easoning | **Science it** | the science rule that connects the evidence to the claim, and what it means for the situation | "…so it keeps the rain out." / "Only a magnet can be repelled." / "The pupa does not feed." |

**Marks = ideas.** A [2] question needs two separate scoring ideas; usually
claim + evidence earns one, the science reasoning earns the other. A [1] "Explain"
still needs the reason — a bare claim scores 0.

Hand signal: **thumb (Say it) → pointer finger taps the question
(Show it) → whole hand "explodes" (Science it!)**. Ask him to do it before writing.

## 2. Same skeleton, different school names

| School label | Maps to |
|---|---|
| Claim – Evidence – **Reasoning** (many schools) | CER |
| Claim/Choice – Evidence – **Concept – Link** | Reasoning split into the science **concept** and the **link** back to the object/situation |
| **Choice – Data – Explain** | CER |
| R.I.S.E. (Read, Identify keywords, Select concept, Express) | reading routine around CER |

If the learner's teacher uses one of these words, use the teacher's words — the
structure is identical. When a 2-mark answer loses a mark it is almost always the
**Link** (one school's word): the answer stops at the science fact and never says what
it means for the face shield / raincoat / magnet in the question.

## 3. Templates by question type

| Question says | Template |
|---|---|
| "Which material is most suitable for X? Explain." | **[Material]**. It is **[property 1]** and **[property 2]** (evidence: ✓ in table / result), so **[what X must do]**. |
| "Do you agree? Explain." | **Yes/No.** [Evidence that decides it]. [Science rule], so [conclusion]. — Never skip "Yes/No". |
| "Explain why [something happened]." | [What was different in this set-up] → [science need/rule] → [so the result]. |
| "Is X living or non-living? Explain." | **Living/non-living.** It can **[characteristic word]** (e.g. respond to changes) — evidence from the story. |
| "Is the experiment fair? Explain." | **No.** [Name the two variables that changed], so we cannot tell which one caused the result. / **Yes.** Only [changed variable] was different. |
| "State the relationship between A and B." | **As A increases, B increases / decreases.** (Name both variables; no numbers needed.) |
| "What is the aim?" | **To find out if/how [changed variable] affects [measured variable].** |
| "Identify the changed / measured variable." | Changed = what *you* chose to be different. Measured = what you *recorded*. |
| "Which stage, W or X? Explain using the results." | **X.** [Data during X vs W]. [Which stage feeds / does not feed]. |
| "Predict… Explain." | [Number/range or direction] because [pattern in the data / rule]. |
| "Give two reasons / two differences." | Two **separate** comparisons, each with both sides: "**E has 8 legs but an insect has 6 legs.**" |
| "State one similarity (do not name the stages)." | "Both have **four stages**." / "Both spend the **least** time as eggs." |
| "How can she make it a fair test / improve it?" | "Use objects of the **same shape/size** but **different materials**" — change only one thing. |
| "Suggest a way to reduce mosquito breeding" | [Action on water] so the [egg/larva/pupa] cannot [survive/breathe/hatch]. |

## 4. Worked examples — weak → strong

**Ex 2 · Magnets.** "Object X moved away from the electromagnet.
What is X? Explain." [2]
- Weak: "A magnet because it moved."
- Strong: "**A magnet.** X was **repelled** by the electromagnet. **Only a magnet can
  repel another magnet** — like poles were facing each other."

**Ex 5 · Fair test.** "Was the experiment with bowls R and T a
fair test? Explain." [1]
- Weak: "No, because the bowls are different."
- Strong: "**No.** The **thickness** of R and T is different as well as the
  **material**, so we cannot tell which one caused the result."

**Ex 6 · Classification.** "Which animal, J (scales, gives birth)
or L (fur, gives birth), could the orang utan be? Explain." [1]
- Strong: "**L.** The orang utan has **fur**, like L, and gives birth to young alive."

**Ex 7 · Mould.** "Which set-up, J (with moisture-absorbing
substance X) or K, had mould? Explain." [1]
- Strong: "**K.** K had no substance X, so the cupcake stayed **moist**. Mould
  (fungi) **needs water/moisture** to grow."

## 5. MCQ routine — "Read · Circle · Cross · Check"

1. **Read** the stem twice. Say in one sentence what the diagram/table/graph shows
   ("taller bar = more light got through").
2. **Circle** the key words: **NOT, MOST, LEAST, BEST, ONLY, MUST, AFTER, BEFORE,
   CORRECT/INCORRECT, ALL**.
3. **Cross** out options you can prove wrong — say the reason.
4. **Check** the last two options against **every** column / every statement.

Statement MCQs (A, B, C, D listed, options "A and B only"…): mark each statement
**T or F** next to it first, then find the option that matches exactly.

Picture options (life cycles, stroke diagrams, magnet arrangements): check every
arrow / label; one wrong arrow kills the option.

Pace: 24 MCQs in about 30 minutes. Star ★ anything over 90 seconds and come back.

## 6. Keyword bank (exact phrases markers look for)

| Topic | Use these words |
|---|---|
| Living things | grow · respond to changes · reproduce · need **air, food and water** to survive |
| Plants / fungi | flowering plants **bear flowers / reproduce by seeds**; ferns reproduce by **spores**; fungi **cannot make their own food**; mould needs **water/moisture, warmth, food** |
| Animals | **hair/fur**, **feathers**, **dry scaly skin**, **moist skin**, **gills**, **gives birth to young alive**, **lays eggs**, **feeds young with milk**; insect: **3 body parts, 6 legs, 1 pair of feelers** |
| Materials | strong · **bends without breaking** (flexible) · **does not allow water to pass through** (waterproof) · **absorbs/soaks up water** · **allows most/least light to pass through** · **floats/sinks** |
| Life cycles | **repeated pattern**, no first or last stage; **larva feeds**, **pupa does not feed**; **nymph** looks like the adult; **moults** (sheds its skin); seed needs **water, air, warmth** |
| Magnets | **like poles repel, unlike poles attract**; **magnetic material**; **only a magnet can repel**; strongest **at the poles**; rests **north–south**; stroke in **one direction**; **more turns / more batteries → stronger** |
| Experiments | **changed / measured / kept the same** variable; **only one variable changed**; **as ___ increases, ___ increases/decreases** |

Phrases that lose marks: "it is light" (for floating), "it is soft" (for
flexible), "it is hard" (for strong), "it can move" (for living), "it is a
metal" (for magnetic), "because it is better".

## 7. Marking at home (parent/tutor)

- 1 mark = 1 correct idea in the scheme. Accept equivalent wording that keeps the
  keyword's meaning ("lets water through" = not waterproof).
- A claim with no explanation on an "Explain" question = 0 for that part.
- After marking, the learner **rewrites one lost-mark answer** using CER and the keyword
  he missed. The rewrite is where the learning happens; skipping it wastes the paper.
- Log every part with an error type (concept · keyword · misread · data ·
  incomplete · slip · blank).
