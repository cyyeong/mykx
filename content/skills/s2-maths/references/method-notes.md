# Method notes: worked steps, common errors, checks

## The worked-step habit

Lower-secondary maths is marked on method, so every answer is a short column of lines, one idea per line:

1. **Name the method** before using it: "Factorise, then set each bracket to zero." "Similar triangles: corresponding sides are proportional."
2. **Write the equation or expression first**, with the numbers in it: "tan 35° = QR/12". Then the calculator.
3. **One operation per line**, done to both sides, with the sign carried along: −3x < 15 → x > −5 (÷ −3, sign reversed).
4. **Round once, at the end**, to 3 significant figures (angles 1 decimal place), with the unit.
5. **Check** with a method different from the one used to solve (below).

When Kix explains, it follows the same column: name the method, one step, ask the learner for the next step. Never show the whole solution at once unless the learner has asked to see it.

**Error types to name after a wrong answer:**

| Type | Looks like | Response |
|---|---|---|
| `concept` | wrong method, confidently | reteach with a small numerical example first |
| `sign` | right method, a sign lost | find the line where it changed; say the rule ("a minus times a minus…") |
| `setup` | the equation or ratio built the wrong way | ask what each letter stands for, in words |
| `arithmetic` | method right, calculation wrong | redo the one line; estimate first next time |
| `rounding` | rounded too early, or to the wrong accuracy | carry the calculator value; round once |
| `misread` | answered a different question (width, not length) | underline what is asked before starting |

## Expansion and factorisation

**Expanding.** Each term in the first bracket multiplies each term in the second: two brackets of two terms make four products. Draw the four arrows if needed. Collect like terms last.

**The three identities** (N5.12) are shortcuts, not new rules:

- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- a² − b² = (a + b)(a − b)

The single most common error is (a + b)² = a² + b². Test it with numbers: (3 + 2)² = 25, but 3² + 2² = 13. The missing 12 is the 2ab.

**Factorising: always in this order.**

1. Common factor first (18p² − 50q² = 2(9p² − 25q²)).
2. Two terms with a minus between squares → difference of two squares.
3. Three terms → ax² + bx + c: find two numbers for the brackets whose product is right, then **expand to check the middle term**.
4. Four terms → group in pairs; each pair must leave the same bracket.

"Factorise completely" means keep going until no bracket can be factorised further. A sum of two terms, such as 3a(2x − y) + 2b(2x − y), is not factorised yet.

**Check:** expand the answer, or substitute a small number (x = 1) into both forms.

## Algebraic fractions and formulae

**Multiplying and dividing.** Turn ÷ into × by inverting the fraction you divide by (only that one). Then cancel numbers and letters separately.

**Adding and subtracting.** Use a common denominator, put each new numerator in brackets, then expand. The minus sign in front of a fraction multiplies the whole numerator: 3(x + 1) − 2(x − 2) = 3x + 3 − 2x + 4.

**Changing the subject.** Undo the formula in reverse order: clear fractions, expand, collect every term with the new subject on one side, **factorise it out**, then divide. If the new subject appears twice, factorising is the step learners skip.

**Finding an unknown in a formula.** Substitute first, then solve the equation that is left. Changing the subject first is optional.

**Check:** pick a value (x = 4), find y from the original formula, then put y into the rearranged formula. You should get x = 4 back.

## Inequalities

An inequality is solved like an equation, with one extra rule: **multiplying or dividing both sides by a negative number reverses the sign.** Adding, subtracting, or multiplying and dividing by a positive number never changes it.

Teach the rule from numbers: 2 < 5, but −2 > −5.

**Number lines.** A filled circle when the end point is included (≤, ≥); an open circle when it is not (<, >). The arrow points the way of the solution.

**Integer questions.** Solve first, then list the next few integers that fit. Test the boundary: for x > −5, −5 itself does not fit, so the smallest integer is −4.

**Check:** substitute one value inside the solution and one outside.

## Linear graphs and simultaneous equations

**ax + by = c** is a straight line. The quickest two points are the intercepts: put y = 0, then x = 0.

**Substitution** when one equation already says y = … or x = …. Put brackets round what you substitute.

**Elimination** when the coefficients can be matched: multiply one or both equations so that one letter has the same coefficient, then add (opposite signs) or subtract (same signs).

**Graphical method.** The solution is the point where the two lines cross; read x and y from that point. A graphical answer is an estimate, so check it in both equations.

**Word problems (N7.10).** Write what each letter stands for, with units ("let $t be the cost of one cup of teh"). One sentence of the problem gives one equation.

**Check:** substitute the pair into **both** equations. A pair that fits only one equation is the most common wrong answer.

## Quadratic functions and equations

**Solving by factorisation.** Make one side 0, factorise, then use "if A × B = 0, then A = 0 or B = 0". From (x − 7)(x + 2) = 0 the solutions are 7 and −2, the numbers that make each bracket zero, not the numbers inside.

**In context**, say which solution is rejected and why ("a width cannot be negative"), then answer what was asked (the length, not x).

**The graph of y = ax² + bx + c:**

- a > 0 → U-shaped, with a minimum point; a < 0 → ∩-shaped, with a maximum point.
- The curve is symmetric about a vertical line, x = (a number). In a table of values, the y-values repeat on either side of it.
- The turning point is on the line of symmetry.

**Check:** put each solution back into the original equation.

## Proportion and map scales

- **Direct proportion:** y = kx. As x doubles, y doubles. y ÷ x is constant.
- **Inverse proportion:** y = k/x, so xy = k. As x doubles, y halves. Workers and days: workers × days is the amount of work.

Find k from the given pair, write the rule, then use it. Ask first: "more of one means more or less of the other?"

**Map scales.** 1 : 25 000 means 1 cm stands for 25 000 cm = 250 m = 0.25 km. For areas, square the length scale: 1 cm² stands for 0.25² = 0.0625 km². Convert units before squaring.

## Congruence and similarity

- **Congruent figures** have the same shape and size. In △ABC ≡ △PQR the letters match in order: A ↔ P, B ↔ Q, C ↔ R, so AB = PQ and angle ABC = angle PQR.
- **Similar figures** have the same shape: corresponding angles are equal and corresponding sides are proportional. For triangles equal angles are enough; for other polygons (rectangles!) the sides must be checked too.
- **Find a side:** write the ratio with the unknown on top: BC/DE = AB/AD. Use whole sides (AB = AD + DB).
- **Enlargement:** every length is multiplied by the scale factor k. A scale factor between 0 and 1 is a reduction. Find the new lengths before any area.

**Check:** the larger figure must have the larger side.

## Pythagoras' theorem and trigonometry

**Pythagoras' theorem:** in a right-angled triangle, (hypotenuse)² = (side)² + (side)². The hypotenuse is opposite the right angle and is the longest side. Finding a shorter side means subtracting.

**Is it right-angled?** Check whether (longest side)² equals the sum of the squares of the other two.

**Trigonometric ratios** (acute angles in right-angled triangles):

- sin θ = opposite/hypotenuse, cos θ = adjacent/hypotenuse, tan θ = opposite/adjacent.
- Label the sides **from the angle in use**. Pick the ratio that links the side you know and the side you want.
- For an angle, use the inverse key: θ = tan⁻¹(12/20).
- Keep the calculator in degree mode.

**Check:** the hypotenuse is the longest side; a small angle has a short opposite side.

## Mensuration

| Solid | Volume | Surface area |
|---|---|---|
| Pyramid | 1/3 × base area × height | sum of the faces |
| Cone | 1/3 πr²h | curved surface πrl, plus the base πr² for a solid cone |
| Sphere | 4/3 πr³ | 4πr² |
| Hemisphere | 2/3 πr³ | curved 2πr², plus the flat face πr² for a solid one |

l is the slant height: l² = r² + h². For a composite solid, split it, find each part, then add (or subtract a hole). Say which faces are hidden where two solids join.

**Check:** a cone or pyramid is one third of the cylinder or prism with the same base and height; volume units are cubed, area units squared.

## Statistics and probability

**Diagrams.** A dot diagram shows each value as a dot above a number line; a stem-and-leaf diagram keeps the actual values in order (read the key); a histogram shows grouped data with equal class intervals.

**Averages.** Mean = sum ÷ number of values. Median = the middle value of the ordered data (the average of the two middle values for an even number). Mode = the most common value. The median is better than the mean when there is an extreme value; the mode suits categories.

**Grouped data.** Use the mid-value of each class: estimated mean = Σfx ÷ Σf. It is an estimate because the exact values are unknown.

**Misleading diagrams.** Look for a vertical axis that does not start at 0, unequal class widths, or pictures scaled in two directions.

**Probability of a single event** = number of favourable outcomes ÷ number of equally likely outcomes. It is always from 0 (impossible) to 1 (certain). P(not A) = 1 − P(A).

## Checking before moving on

A ten-second check after every answer catches most slips:

| Topic | Quick check |
|---|---|
| Expansion and factorisation | expand back, or put x = 1 into both forms |
| Changing the subject | a value round trip (x → y → x) |
| Inequalities | test one value inside and one outside |
| Simultaneous equations | the pair in both equations |
| Quadratic equations | each solution in the original equation; reject impossible ones in words |
| Proportion | more or less? does the answer go the right way? |
| Similar figures | the larger figure has the larger side |
| Pythagoras and trigonometry | the hypotenuse is the longest side |
| Mensuration | the unit is squared or cubed; the size is sensible |
| Probability | between 0 and 1; all outcomes add to 1 |
