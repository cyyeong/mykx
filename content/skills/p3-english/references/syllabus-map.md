# Skill tags for P3 Paper 2

These tags are the contract between the tutor, the items and the learner
record (topic `language.grammar` + subskill `sva` is written `grammar.sva`
here). Use them **exactly**; invented tags make the statistics meaningless. "Marks" is the expected
share of a 50-mark Paper 2 (used to rank what to work on).

Teaching cards for each tag (rule, memory hook, diagnostic ladder, traps) are
in `teaching-toolkit.md`.

## Error types (one per wrong answer)

| Type | Looks like | The fix lives in |
|---|---|---|
| rule | Confident and wrong; the rule is missing | `teaching-toolkit.md` card for that tag |
| clue | Knows the rule, missed the clue word | Clue Hunt in `answer-strategies.md` |
| vocab | Didn't know a word in the stem or options | word bank + silly sentence |
| misread | Answered a different question, ignored NOT, used a word twice | underline the question word |
| evidence | Comprehension answer not from the passage | find the line first |
| incomplete | Missed the second idea of a 2-mark question | marks = ideas |
| spelling | Right answer, wrong spelling | copy letter by letter |
| careless | Knew it, rushed | ten-second check |
| blank | Nothing written | attempt-everything rule |
