# Answering techniques: how marks are won

Built from school marking schemes (private reference), SEAB's assessment objectives, and
published analyses of recent PSLE papers.

## 1. Booklet A (MCQ, 60 marks) — the R.U.L.E. routine
Teach it as four moves the learner can say aloud:
1. **R — Read twice, mark the question word.** Circle *not / only / definitely / best / most likely /
   which two*. "Definitely correct" means: pick only what the data proves, not what is plausible.
2. **U — Underline what changed and what was measured** in any experiment stem; find the
   *changed variable* in the table/graph before reading options.
3. **L — Line up each option with the evidence.** Cross out every option you can *disprove*
   (one wrong word disproves a whole option). For "A and B only"-type options, judge each
   statement true/false first, then match the combination.
4. **E — Explain your pick in one sentence.** If the learner cannot say *why* in one sentence, the learner is
   guessing — reread the stem.

MCQ-specific traps seen repeatedly in school papers:
- **Graph direction**: the population that falls is the *prey*; the temperature that stays flat is a
  *change of state*; a line that keeps rising means the variables are related "as X increases, Y increases".
- **Table-match options**: check each column separately; eliminate rows with one wrong cell.
- **"Which is NOT…"**: light and shadows are never effects of a force; deforestation never *absorbs* CO₂.
- **Circuits**: trace the loop with a finger from the battery; every component on the same
  unbroken path is in series; branches are independent. Two opposed batteries = no current.
- **Linked pairs** (two MCQs, one scenario): answer the first, then re-read the scenario before the second —
  the second usually tests the *other* variable or the *other* organism.
- **Real-life contexts** (food parcels, plants on a bus, balls on a ship deck): find the *one* concept behind
  the story (heat conductor? light blocked? less oxygen?) and ignore the decoration. Test an option by
  imagining its opposite ("if the leaf were metal…").
- Never leave a blank; a 25% guess beats 0. Time: ~1.5 min per MCQ, 45–50 min for Booklet A, leaving
  ~55 min for Booklet B.

## 2. Booklet B (structured, 40 marks) — the C.E.R. spine
Every explanation = **Claim → Evidence → Reasoning**, written as one or two sentences that *link* them:
- **Claim**: answer the actual question first ("Cup A", "The population of D increases", "By wind").
- **Evidence**: the observation/data the question gave ("cup A has no cotton wool", "fewer E remain to feed on D").
- **Reasoning**: the science keyword sentence ("air is a poor conductor of heat so heat is lost more slowly").
Markers award by *marking points*; count the marks: [2] = two distinct points; [3] = three. Under-writing
loses more marks than over-writing, but padding wastes time — one idea per sentence.

### Question-type frames (fill the blanks)
| Command word | Frame | Example |
|---|---|---|
| **State / Name / Identify** | The exact word(s). No explanation. | "Gravitational force and frictional force." |
| **Explain why X happened** | *X happened because [cause] → [effect] → [what the question asked].* | "The white fumes formed because hot water vapour from the rice met the cooler air, lost heat and condensed into tiny water droplets." |
| **Explain how [adaptation] helps it survive** | *[Feature] allows it to [action], so it can [get food / escape predators / keep warm / reproduce].* | "The webbed feet push a larger area of water, so it swims faster to catch fish." |
| **Predict / What would happen … Explain** | *Choice.* Then *because* chain. | "Cup A. It has no insulation, so heat is lost to the cooler surroundings faster." |
| **Compare / Why more in B than A** | Use comparative words: *more, less, faster, slower, greater, further*. State BOTH sides if 2 marks. | "Muscles need more energy when running, so the heart pumps faster to carry more oxygen and digested food and remove more carbon dioxide." |
| **Relationship between X and Y** | *As X increases, Y increases/decreases.* (Nothing else.) | "As the mass of the ball increases, the distance travelled decreases." |
| **Aim of the experiment** | *To find out how [changed variable] affects [measured variable].* | "To find out how the distance of the lamp affects the volume of oxygen collected." |
| **Hypothesis** | *The [greater/nearer] the [changed variable], the [greater/shorter] the [measured variable].* | "The larger the surface area of the blades, the shorter the time taken for the bulb to light up." |
| **Conclusion** | Same shape as hypothesis but only what the data shows; add "based on the results". | |
| **Fair test / variables** | Changed: one only. Measured: the result. Kept the same: everything else — name 2 specific ones (same volume of water, same starting temperature, same type of plant, same distance). | |
| **Why repeat the experiment?** | *To identify anomalous results and obtain an average so the results are more reliable.* | Reliability ≠ accuracy |
| **How to make it more accurate?** | Remove a measurement error: read at eye level; start the ruler at the water surface; wait for water to settle; add oil to stop evaporation from a measuring cylinder; use a finer scale. | Accuracy ≠ reliability |
| **Purpose of the control set-up** | *To show that [the change in the measured variable] is due to [the changed variable] and not other factors / for comparison.* Describe it as identical except without the changed factor. | "An identical bus with no plants on its roof." |
| **Describe how to carry out** | Numbered steps: set-up (same…, same…) → change the one variable → measure with the named apparatus → repeat/compare. Use ONLY the apparatus in the picture. A labelled sketch is welcome. | |
| **Energy conversion boxes** | Name the form AND the object: *elastic PE (spring) → KE (piston) → KE (soap)*. | |
| **Draw a circuit** | Each component on a complete loop; parallel = separate branch; a switch that controls X sits on X's branch; batteries same direction; symbols only. | |
| **Draw a graph/bar** | Same scale as the others; label; bar height read from the trend given. | |
| **Label poles** | Like poles face each other when rings float apart (repel); attracted ends are unlike. | |

## 3. Keyword bank by topic (use these words; they map to marking points)
- **Heat**: gains heat / loses heat · hotter → colder · good/poor conductor of heat · slower/faster rate · expands / contracts · same temperature as surroundings.
- **Water**: gains heat → evaporates → water vapour · water vapour (in the air) touches the cooler surface → loses heat → condenses → water droplets · exposed surface area · boiling at 100 °C.
- **Light**: light travels in a straight line · blocked by opaque · some light passes through translucent · reflected into our eyes · nearer the light source → bigger shadow.
- **Electricity**: closed circuit · open circuit · current flows · conductor / insulator · in series / in parallel · fuses · same brightness / dimmer / brighter.
- **Forces**: gravitational force pulls it down · frictional force acts opposite to motion / between … and … · elastic spring force · magnetic force of attraction/repulsion · greater force needed.
- **Energy**: gravitational potential energy · kinetic energy · elastic potential energy · converted to · heat and sound energy lost · more … so more ….
- **Environment**: population increases/decreases · less food / fewer predators · feeds more on · competition for light, water, mineral salts and space · camouflage · structural / behavioural adaptation · habitat destroyed.
- **Plants**: water-carrying tubes · food-carrying tubes · tiny openings · photosynthesis · light, carbon dioxide, water · sugar/food, oxygen · respiration.
- **Human**: oxygen-rich / carbon-dioxide-rich · digested food absorbed into the blood · heart pumps faster · more oxygen & digested food · release more energy.
- **Reproduction**: pollination (anther → stigma) · fertilisation (male + female reproductive cells fuse in the ovary) · ovary → fruit, ovule → seed · dispersed by … · germination needs water, oxygen, suitable temperature.
- **Matter**: has mass · occupies space · no definite shape · can be compressed · melting/boiling point.
- **Experiments**: changed variable · measured variable · kept the same · fair test · reliable (repeat, average) · accurate · control set-up · anomalous.

## 4. The misconception list (each one has cost marks in school papers)
1. "Cold flows into the drink" → *heat flows out of the drink.*
2. "Water droplets on the cold can came from inside the can" → *from water vapour in the surrounding air.*
3. Heat = temperature → *heat is energy; temperature is how hot; more water at same temperature holds more heat.*
4. "Plants stop respiring in the day / only animals respire" → *plants respire 24 h.*
5. "Roots absorb food" → *roots absorb water and mineral salts; leaves make food.*
6. "More bulbs on a branch = brighter" → *in series each is dimmer.*
7. "Current is used up by the first bulb" → *same current through a series loop.*
8. "The rising line is the prey" → *the falling one is.*
9. "Friction always bad / depends on surface area" → *friction also gives grip; depends on roughness and how hard surfaces press, not area.*
10. "Gravity is bigger higher up" → *gravitational force stays the same; GPE is what rises with height.*
11. "Energy is used up" → *converted, mostly to heat.*
12. "Nymph = larva" → *nymph resembles adult (3-stage); larva does not (4-stage).*
13. "Seeds need light to germinate" → *water, air (oxygen), suitable temperature only.*
14. "Splitting fruits travel far" → *they land close to the parent.*
15. "Anything attracted to a magnet is a magnet" → *only repulsion proves a magnet.*
16. "Air has no mass / air cannot be squeezed" → *air has mass and can be compressed.*
17. "Boiling = evaporation" → *evaporation at any temperature from the surface; boiling at 100 °C throughout.*
18. "Fruit comes from the ovule" → *fruit ← ovary; seed ← ovule.*
19. "Reliable = accurate" → *repeat → reliable; better measuring → accurate.*
20. "Mist is a gas" → *mist is tiny liquid droplets; water vapour is invisible.*

## 5. Time and paper management (exam day)
- Booklet A first, steady pace: skip and mark any MCQ over 2 min, return later. Shade as you go.
- Booklet B: read all parts of a question before writing (a) — later parts often reveal the intended concept.
- Write the claim first, then the reason. Leave no part blank; a correct one-word claim can earn 1 of 2.
- Last 5 minutes: check every OAS row is shaded once; check units (cm³, °C, s) and comparative words.
